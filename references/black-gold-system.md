# 黑金主题系统｜唯一视觉真源

本文件是 `minimal-editorial-tech + black-gold-editorial` 的唯一主题依据。它定义主题 Token、稳定组件、首帧语义主视觉、人物呈现和黑金视觉验收；不定义内容路由、卡片几何或日常生产顺序。

## 1. 固定 Token

| 角色 | Token | 用途 |
|---|---|---|
| 连续母版 | `#10100F` | 全图无前景区域；所有阅读区从同一母版裁切 |
| 深色面板 | `#181816` | 内容层级与编辑容器；不可反过来铺满整图 |
| 标题暖白 | `#F0ECE2` | 主标题、模块标题、关键事实 |
| 唯一金色信号 | `#CCAA77` | 主标题关键词，以及每阅读区至多一个关键结论/行动/事实 |
| 正文与元信息 | `#94918A` | 正文、说明、日期、标签、元信息；只以字号和字重区分 |

- 不使用第二种金色、霓虹、金箔、蓝紫科技色、外发光或新增投影。
- 主标题必须从冻结文案中选取**恰好一处**核心关键词或短语使用 `#CCAA77`；在 Plan 逐字记录。
- 除标题信号词外，每个阅读区最多一处金色短语，且必须承担结论、行动、成果或关键事实；正文不可大面积染金。

## 2. 视觉语言与稳定组件

- 气质为连续炭黑、克制编辑排版、细腻烟熏亚克力、哑光石墨、暖灰实体与小面积黄铜。
- 展示标题使用笔画清晰、横排稳定且许可明确的中文衬线展示字；视觉锚点为 Noto Serif SC Bold 或同等授权替代。正文、日期、价格、资源与行动事实使用稳定中文无衬线，并在 Plan 记录实际字体、字重与许可。不得以系统字体“内部预览”替代正式交付字体选择。
- 章节号仅在有真实章节导航时启用：右侧定位层，`right=92px ±8px`，字号 `176–184px`，与对应主标题首行顶边 `±8px` 对齐；不能移到左侧内容轴或压住文字。
- 外侧轨道若启用，默认 `x=48 / 1032`；正文与承载正文的容器仍使用 `x=112–968` 安全轴。内部竖线最多三条；距外轨小于 `64px` 的冗余线必须删除。
- 标题、正文、卡片与真实证据优先；轨道、网格、章节号只服务定位，不能替代信息层级。

## 3. 首帧语义主视觉

- 首帧语义主视觉为必选项，且必须由 ImageGen 生成：先读标题，再读主视觉。真实来源资产与程序化结构可服务后续阅读区或作为辅助证据，但不得取代首帧主视觉。主视觉必须解释标题中的对象、关系或变化；泛科技物件、盘旋线、空白节点或无关装饰不合格。生产前必须阅读批准基线，并在 Plan 记录借用的质量目标与明确不复用项。
- 每张首帧恰好有 **1 个视觉主实体 / 视觉中心**。辅助关系数量不设上限，但每一项都必须写明“图元 → 冻结文案的对象、输入、输出、变化或证据”，视觉显著性低于主实体，且不能抢夺标题之前的第一阅读落点。数字、日期与准确术语由后置文字表达，不要求模型逐项具象化。
- 标题/副标安静区默认 `x=112–968, y=160–620`；3D 主体推荐区 `y=680–1600`。可按内容调整，但不可侵占必要文字。ImageGen 不生成必要文字、数字、二维码、Logo 或真人身份。
- 首帧主视觉必须以**实际可见 bbox**而非原始图片画布定位。Plan 与 Manifest 必须记录 `copy_anchor_bottom`（V1 最后一个必要文字或分隔线的底边）、`copy_group_height` 与 `hero_visible_bbox`：主视觉可见顶部距 `copy_anchor_bottom` 必须为 `64–144px`，可见高度不得小于 `max(560px, 1.2 × copy_group_height)`。不满足时先放大并上移；不得把标题下方的无意义留白留给透明图片画布或过小主体。
- 上述几何关口不授权主视觉侵占文字安静区。若主体需要延展，优先向下延展，并按声明的 `edge_mode` 在下缘收束；不得靠降低字号、压缩标题组或用独立图片卡补空。
- 资产进入整图前，必须进行一次局部目视验收：唯一视觉中心、关系可读、透视可信、材质细腻、无烘焙文字、无红黄灰边、文字安静区和边界均通过。任何一项失败都不得进入整图渲染；允许一次受限替换生成。
- 质感应细腻而非粗糙：禁止粗颗粒、脏污石材、夸张反射、失真透视、高反差发光与独立矩形图片卡。
- 在 Plan 写明 `edge_mode`：
  - `native-alpha`：仅当复杂材质的原生透明边缘经检查干净时使用；必要时只在资产自身下缘短距离 alpha 收束至 `#10100F`。
  - `dark-scene-canvas-mask`：复杂 3D 主视觉默认路径。将生成图置于连续母版上，以与母版同色的 `#10100F` 半透明融合蒙版处理资产区域，并在接近下缘或相邻阅读区处渐深至母版。蒙版不可使用纯黑，不能跨出资产区域成为整帧遮罩，也不得造成独立矩形边界或首二阅读区暗带接缝。

## 4. 人物呈现

真人只使用用户确认的原图，绝不由 ImageGen 重生、改脸或替换。先执行一次安全本地去背景尝试；不得为真人反复调用 ImageGen。

1. `transparent`：仅当在 `#10100F` 母版预览中确认外部背景真实透明、且发丝、轮廓、服饰和身份可信度完整时使用透明 PNG。不添加矩形底板或补背景，只允许人物自身下缘在必要时渐隐。人物**可见头顶**与人物介绍文字组顶部 `intro_text_top` 对齐 `±8px`。
2. `source-crop`：仅当安全去背景会损失发丝、轮廓、服饰或身份可信度时使用。Plan 记录尝试结果与降级原因；原图合理裁切，完整保留头顶、脸和下巴，不使用透明人像的渐隐模板。**图片矩形顶部**与人物介绍文字组顶部 `intro_text_top` 对齐 `±8px`。

- `intro_text_top` 是姓名或身份信息的第一个关联文字锚点，不能使用泛章节标签（如“导师”）。
- 人物可以放大以匹配关联文字区的视觉重量，但不能为制造重叠而故意左移进入文字区。
- `transparent` 使用实际可见 bbox；`source-crop` 使用图片矩形 bbox。两者高度都不得超过关联文字区 `bottom - top`；透明路径超出时只在人物自身下缘收束，不能裁头或延伸进无关阅读区。
- 透明边缘必须干净，无白边、灰边、旧背景残留或新增阴影；“文件含 Alpha 通道”不是通过证据，必须在母版色上目视确认。

## 5. 编辑信息模块

适用于卡片、双轨、权益项、行动面板和任意“标题 + 说明”模块：

- 标题：`#F0ECE2`，字重高于正文；说明/正文：`#94918A`，Medium。
- 标题到首段说明的间距 `G = 1.5–2.0 × P`，其中 `P` 是说明段间距。
- 容器默认内缩 `32px`。文字、标签、数字、二维码与分隔线都从父容器 `rect + padding` 计算；修改卡片几何时必须同步重算全部子元素。
- 内容足以区分时，不用中段装饰物挤占文字横向宽度；优先让文字铺满安全轴。
- 分条内容确有快速区分收益时，icon 必须由每条关键词一一导出。优先使用许可明确、同一套视觉语言的图标库；图标库无法表达且收益明确时，才可用一次 ImageGen 生成无文字、透明背景、同组风格的 icon 资产。加号、方框、菱形等基础几何形不视为语义 icon，除非源文案本身就在表达该形状。

## 6. 主题验收

在最终图与 360px 预览检查：

- 母版无前景区域均回到 `#10100F`，阅读区边界前后无额外暗带。
- 启用的章节号均在右侧槽位、与标题对齐且不碰撞。
- 主标题只有一处已声明的金色关键词；其余金色仅承担明确语义职责。
- 首帧标题优先、主视觉恰有一个视觉中心、辅助关系不争夺层级、语义相关、透视和材质可信、文字安全区干净；`dark-scene-canvas-mask` 无矩形边界或接缝。
- 人像完整、无白边；`transparent` 与介绍文字组以可见头顶对齐，`source-crop` 与介绍文字组以图片矩形对齐，且没有不透明底板。
- 黑金主题不新增投影、外发光或悬浮阴影。
