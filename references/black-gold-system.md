# 黑金主题系统｜唯一视觉真源

本文件定义黑金 Token、首帧、人物、章节导航与信息模块；不定义内容路由或具体卡片几何。

## 1. 固定 Token

规则归属：本文件维护颜色、材料与首帧视觉；`text-rendering-rules.md` 维护字号/字重；`layout-rules.md` 维护内容轴、导航与通栏几何；人物契约维护人物关系。配方坐标是起点，不覆盖这些底线。历史案例的旧字号、旧颜色和固定帧高不是生产规范。

| 角色 | Token | 用途 |
|---|---|---|
| 连续母版 | `#10100F` | 全图无前景区域 |
| 深色面板 | `#181816` | 内容层级与编辑容器 |
| 标题暖白 | `#F0ECE2` | 主标题、模块标题、关键事实 |
| 唯一金色信号 | `#CCAA77` | 标题关键词、结论、行动、关键产出或关键事实 |
| 正文与元信息 | `#94918A` | 解释正文、说明、非重点元信息 |

- 不使用第二种金色、霓虹、金箔、蓝紫科技色、外发光或新增投影。
- 主标题默认从冻结原文中选一处核心关键词或短语使用金色；若原句有多个不可替代的核心关键词，分别用独立标记和独立 Plan 行登记。不得为了换行、视觉平衡或句尾装饰把整段尾句染金。
- 每个阅读区最多一处额外金色短语；流程、课程安排和阶段路径中的“关键产出”及对应结果可用它高亮。普通解释正文不可大面积染金。

## 2. 字体、章节导航与结构线

- 标题使用 Google Fonts `Noto Serif SC` 700。长解释段、流程说明、讲师履历、准备事项和卡片说明使用 `Noto Sans SC` 400；模块/章节标签、日期、价格、行动和关键数据使用 `Noto Sans SC` 500 或更高。字体不随 Skill 打包；浏览器必须从 Google Fonts 真实加载，不得依赖系统字体回退。
- 每个**非首帧**大阅读模块配置一个右侧、低对比的大章节导航号：`right=92px ±8px`、字号 `176–184px`。数字从首帧后的首个内容模块 `01` 连续编号，顶部与左侧模块眉题/章节标签顶部对齐 `±8px`，不与下方大标题对齐；它必须明显大于模块内 `01/02` 小序号，且不得压住标题或正文。
- 外侧轨道若启用，默认 `x=48 / 1032`；正文和内容容器仍使用 `x=112–968` 安全轴。细轨道、结构线和章节号只服务模块层级与阅读关系，不能挤占文字宽度或变成无意义网格。

## 3. 首帧主视觉

主题场景优先使用竖向构图（如 2:3 或 3:4），上下预留自然融合空间；不把横向场景简单裁成狭长横条。场景位置跟随主标题底部，而不是以整组文案底部或固定 y 坐标为锚；标题增加行数时同步下移视觉、扩展封面高度，不能缩字。

- 首帧顶部只保留一个活动/项目语境眉题；相同或高度相近的品牌、活动、课程、栏目名不得以两条小标题重复。主标题承担核心主张，副标题只补充主标题与眉题均未提供的新信息；这一语义去重必须人工复核。
- 首帧必须标题第一、主视觉第二，且只有一个视觉中心。`portrait_hero_decision=theme-imagegen` 时制作内容主题画面，导师/嘉宾人像如有则用于中段；`portrait_hero_decision=mentor-portrait-by-request` 时读取 [portrait-first-frame-contract.md](portrait-first-frame-contract.md) 选择 P01–P04。该内部决定来自确认稿同轮的第一屏普通语言选择。
- `[data-hero-surface]` 是承载主视觉的连续暗场景，横向到达画布两侧，包含唯一 `[data-hero]`。主题场景的表面上缘应与主标题底部轻叠或接近（浏览器测量偏移约 `-64–+32px`），让画面从标题后方自然生长；副标题可以覆盖在场景上。顶部渐入母版、底部自然渐隐，无透明抠图感、独立图片卡、横向切线或矩形边界。首帧下方内容随场景整体上移，不保留原有空场。
- 副标题若因叠图失去对比，只在上部文字附近叠加与母版同色的半透明渐变，遮罩不透明度约 `40%–60%`，向下归零；仍须透出场景，不得用实心黑块抹掉画面。标题保持第一阅读落点，副标题和场景均清楚可辨。实际透图与融入质量为人工复核项。
- 整体压低亮度、饱和度与暖黄，以炭黑、暖灰、烟熏亚克力为主，仅留少量黄铜高光。AI 视频、AIGC 影像或 AI 创作类活动使用电脑、剪辑工作台、分镜、胶片或视频生成工作流等真实工具语义，不得误作纯手工电影道具或泛科技装饰。
- ImageGen 不生成可读文字、数字、Logo、二维码、水印或真人身份。每项辅助关系必须低于主实体，并能映射到冻结文案的对象、输入、输出、变化或证据。
- Plan 和 Manifest 记录主标题底部、`copy_anchor_bottom`、`copy_group_height`、`hero_visible_bbox` 与 `surface_bbox`。主题场景以表面上缘对齐主标题底部；现有 Manifest 的 `visible_bbox` 是 DOM 外框，不能代替对渐变后首个可见像素的人工判断。可见高度仍至少 `max(560px, 1.2 × copy_group_height)`；人物首帧继续遵循其独立契约。
- 局部验收逐项检查顶部融合、底部融合、标题优先级、低亮度/低饱和度/低暖黄、单一视觉中心、语义相关性、透视、材质、无烘焙文字和文字安静区。任一失败不得进入整图；默认只允许一次命名失败的替换。

## 4. 人物与信息模块

真人只使用用户确认原图，绝不由 ImageGen 改脸或重生。正文人物模块可按原图质量选择 `transparent / masked / source-crop`；人像首帧不使用原图矩形裁切，必须遵循 P01–P04 的透明资产、头部尺度、肩部实体、下缘渐隐和人物—说明绑定合同。所有人物均须完整保留头顶、脸、下巴及源图中原本完整的肢体。

信息模块中，标题为暖白且高于正文；解释性说明为正文色 Regular。日期、行动、关键数据和明确关键产出可为 Medium 或更高。标题与首段说明的间距为说明段距的 `1.5–2.0 ×`；容器默认内缩 `32px`。

## 5. 主题验收

- 母版空白回到 `#10100F`，阅读区间无额外暗带或硬接缝。
- 大阅读模块的章节导航号在右槽、对齐眉题、明显大于内部序号且无碰撞。
- 金色只承担能逐字追溯到原文的标题关键词、结论、行动、关键产出或关键事实；主标题金色词与原文依据必须逐项登记在 Plan，语义准确性须人工复核。
- 首帧标题优先，主视觉融合母版、唯一且语义相关；亮度/饱和度/暖黄克制，文字安全区干净。
- 轨道、结构线和图文关系形成连续编辑节奏，不重复平铺模块，不遮挡正文。
